\subparagraph{Mô tả tổng quan}

\begin{itemize}
\item Guest nhập địa chỉ Email và mật khẩu, nhấn nút Đăng ký trên Web Frontend.
\item Web Frontend gọi hàm đăng ký với Email và mật khẩu, gửi yêu cầu \texttt{POST /supabase-auth-service/auth/v1/signup?redirect\_to=...} qua API Gateway. Gateway thực hiện định tuyến và chuyển tiếp yêu cầu đến Auth Service.
\item Auth Service khởi tạo tài khoản mới trong Database ở trạng thái chưa kích hoạt (\texttt{email\_confirmed\_at = null}).
\item Auth Service yêu cầu Supabase Email gửi một thư điện tử chứa liên kết xác thực tài khoản, với \texttt{redirect\_to} trỏ về \texttt{/auth/callback} của Web Frontend.
\item Auth Service phản hồi đăng ký thành công về cho Web Frontend thông qua API Gateway, Frontend chuyển sang trạng thái \texttt{verify-email} và hiển thị thông báo yêu cầu người dùng kiểm tra hòm thư điện tử.
\end{itemize}
