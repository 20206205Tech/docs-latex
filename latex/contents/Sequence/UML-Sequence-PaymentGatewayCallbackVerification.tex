\paragraph{Sơ đồ tuần tự luồng Pha Gateway gửi callback/IPN và Payment Service xác minh giao dịch}

Pha này mô tả phần đầu của callback/IPN sau khi User thao tác thanh toán trên Payment Gateway. Payment Service nhận callback public, xác minh chữ ký qua Payment Gateway Selector, đối chiếu transaction theo \texttt{txnRef}, kiểm tra số tiền và trạng thái hiện tại. Nếu transaction đang \texttt{pending} và thanh toán thành công, luồng chuyển sang pha 3 để cập nhật transaction, subscription và outbox.

\subparagraph{Mô tả tổng quan}
\begin{itemize}
\item \textbf{Gửi callback/IPN:} Payment Gateway gọi \texttt{GET/POST /code-payment-service/subscriptions/payment-callback/\{provider\}}. Endpoint này là public và nhận dữ liệu qua query hoặc body tùy provider.
\item \textbf{Xác minh IPN:} Payment Service gọi Payment Gateway Selector để thực hiện \texttt{verifyIpn(requestData, provider)} và nhận kết quả gồm \texttt{isValid}, \texttt{isSuccess}, \texttt{txnRef}, \texttt{amount}, \texttt{providerTransId}, \texttt{message}.
\item \textbf{Đối chiếu transaction:} Nếu chữ ký không hợp lệ, không tìm thấy transaction hoặc số tiền không khớp với \texttt{finalAmount}, service trả lỗi theo định dạng provider. Nếu transaction đã \texttt{expired} hoặc không còn \texttt{pending}, service không xử lý lặp.
\item \textbf{Nhánh thất bại:} Nếu IPN hợp lệ nhưng gateway báo thanh toán thất bại, service gọi \texttt{failPayment} để chuyển transaction sang \texttt{failed}, lưu transaction và trả phản hồi lỗi tương ứng cho provider.
\item \textbf{Nhánh thành công:} Nếu IPN hợp lệ, transaction còn \texttt{pending} và gateway báo thành công, service lưu metadata thanh toán tạm thời rồi chuyển sang pha 3 để hoàn tất cập nhật transaction, subscription, outbox và domain event.
\end{itemize}
