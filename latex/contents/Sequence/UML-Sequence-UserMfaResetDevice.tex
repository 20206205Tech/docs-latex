\subparagraph{Mô tả tổng quan}

\begin{itemize}
\item Để thay đổi thiết bị, User yêu cầu hủy liên kết thiết bị cũ thông qua giao diện Web Frontend trong trang cá nhân. Yêu cầu này chỉ được chấp nhận khi phiên xác thực hiện tại đã đạt cấp độ bảo mật cao nhất (AAL2).
\item Frontend thực hiện cuộc gọi API \texttt{DELETE /factors/\{factorId\}} qua Kong Gateway gửi tới Auth Service.
\item Auth Service tiến hành xóa (hoặc đánh dấu đã hủy kích hoạt) factor cũ và gửi phản hồi thành công về cho Frontend. Frontend tải lại danh sách factor; khi không còn factor đang hoạt động, giao diện hiển thị trạng thái chưa kích hoạt MFA cùng nút \texttt{Kích hoạt ngay}.
\item Khi User chọn \texttt{Kích hoạt ngay}, Frontend điều hướng sang trang \texttt{/auth/mfa} và bắt đầu lại quy trình kích hoạt (Enrollment) cho thiết bị mới: gửi \texttt{POST /factors} để nhận QR Code, Secret Key và Factor ID mới của thiết bị mới.
\item User quét mã QR bằng ứng dụng Authenticator mới và nhập mã TOTP mới. Frontend gửi các yêu cầu Challenge và Verify để hoàn tất xác minh. Khi thành công, Auth Service cập nhật trạng thái factor mới thành \texttt{verified}, đồng thời cấp lại token AAL2 mới để khôi phục hoàn toàn quyền truy cập.
\end{itemize}
