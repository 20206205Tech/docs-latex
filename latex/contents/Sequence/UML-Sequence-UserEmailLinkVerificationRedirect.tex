\paragraph{Sơ đồ tuần tự luồng Xác nhận liên kết từ Email (Email Link Verification \& Redirect)}

\subparagraph{Mô tả tổng quan}
\begin{itemize}
\item Người dùng click vào link trong email. Yêu cầu chuyển qua Kong Gateway tới Auth Service để đối chiếu token trong Supabase Database.
\item Nếu hợp lệ, Auth Service trả về HTTP 302 Redirect hướng trình duyệt của người dùng đến địa chỉ \texttt{/auth/callback?type=recovery} của Web Frontend kèm theo token tạm trong URL Hash.
\item Frontend nhận callback, lưu trữ token từ Hash và chuyển hướng người dùng sang \texttt{/auth/mfa?next=/auth/reset-password}; sau khi hoàn tất MFA, hệ thống mới điều hướng tới trang đặt lại mật khẩu.
\end{itemize}
