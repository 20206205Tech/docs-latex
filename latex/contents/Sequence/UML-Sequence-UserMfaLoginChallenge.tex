\subparagraph{Mô tả tổng quan}

\begin{itemize}
\item Khi đăng nhập, hệ thống chỉ cấp Access Token tạm thời ở cấp độ AAL1 (\texttt{aal = aal1}).
\item Web Frontend phát hiện cấp độ token là AAL1, lập tức chặn quyền truy cập và chuyển hướng trình duyệt sang trang nhập mã TOTP (\texttt{/auth/mfa}).
\item User điền mã TOTP lấy từ ứng dụng di động. Frontend thực hiện luồng thách thức/xác thực tương tự qua Gateway gửi tới Auth Service.
\item Khi xác minh thành công, Auth Service nâng cấp phiên đăng nhập lên cấp độ AAL2 (\texttt{aal = aal2}), cấp Access Token mới và gửi về cho Web Frontend để cho phép người dùng đăng nhập chính thức vào hệ thống (\texttt{/chat}).
\end{itemize}
